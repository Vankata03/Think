# Think

Think is a daily practice app: one curated line, one question and one action per day, with private journaling, thinking paths and a focus timer. This glossary fixes the words the product and its design use.

## Language

**Practice**:
One day's unit of content: a daily line, its question and its move, curated as a matched triple.
_Avoid_: Quote of the day, exercise, prompt set

**Daily line**:
The curated sentence shown on Today, from public-domain sources or the house voice.
_Avoid_: Quote, motivation, affirmation

**Move**:
The concrete action paired with the daily line, marked done by the user.
_Avoid_: Task, action item, challenge

**Question of the day**:
The private prompt whose answer becomes a journal entry.
_Avoid_: Reflection prompt, daily question

**Journal**:
Everything the user wrote: answers, notes, retros, focus notes and weekly-review reflections. Never holds saved lines.
_Avoid_: Diary, notes app, history

**Saved line**:
A daily line the user kept for later, reached from Today.
_Avoid_: Favourite, bookmark, liked quote

**Retro**:
The evening retrospective entry for a day.
_Avoid_: Evening review, reflection

**Ritual**:
The three daily acts of a practice: answering the question, doing the move and writing the retro. What Today walks the person through.
_Avoid_: Routine, checklist, daily tasks

**Day arc**:
The half circle on Today that shows the day from 06:00 to 22:00, the current hour and which acts of the ritual are done. Replaces the activity log.
_Avoid_: Day rail, activity log, progress bar, tracker

**Weekly review**:
A once-a-week practice summary plus one reflection; the summary lives on Progress, the reflection in the Journal.
_Avoid_: Weekly report, recap

**Path**:
A multi-step programme (Deep focus, Clear thinking) with independent, repeatable runs.
_Avoid_: Course, programme, track

**Focus session**:
A timed work interval with an intention and a close flow; completing one counts as practice.
_Avoid_: Pomodoro, timer run

**Meaningful practice**:
What completes a day and feeds the streak: an answer, a move, a path step or a focus session, never merely opening the app.
_Avoid_: Activity, engagement, check-in

**Streak**:
Consecutive days of meaningful practice; a missed day reads "Begin again", never guilt.
_Avoid_: Chain, run

**Progress**:
The tab that shows evidence of practice: streak, achievements, stats, focus history, weekly review. Also the door to Settings.
_Avoid_: Profile, account, me

**Achievement**:
A permanent medal or milestone earned through streaks, paths or focus sessions.
_Avoid_: Badge, trophy, reward

**Empty state**:
A screen or section with nothing in it yet because the user has not created anything: no journal entries, no saved lines, no focus history.
_Avoid_: Blank state, zero state, placeholder

**No-match state**:
Content exists but the active search or filters hide all of it.
_Avoid_: Empty results, nothing found

**Begin-again state**:
Something ended and can be restarted without guilt: a lapsed streak, a completed path.
_Avoid_: Reset state, failed state, broken streak

**Locked state**:
Content exists but is gated: the journal behind its lock, a path behind the previous one, an achievement not yet earned.
_Avoid_: Disabled, unavailable, greyed out

**Unavailable state**:
Content or storage could not be loaded or found; distinct from empty, which is a normal condition.
_Avoid_: Error screen, empty state

**Chrome**:
The navigation layer the system draws: tab bar, navigation bar, toolbar items, floating action, sheet dismissal. Distinct from content, which Think designs.
_Avoid_: Header, custom bar, nav

**Hero**:
The one piece of content a screen exists for, shown in a card at the top: the daily line on Today, the timer on Focus, the streak on Progress.
_Avoid_: Featured card, banner, header card

**Primary action**:
The single yellow action on a screen. Lives floating bottom-trailing, inside the hero, or in the trailing toolbar; never more than one per screen.
_Avoid_: CTA, main button, call to action
